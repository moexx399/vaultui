## v0.3.0 - 2026-10-28
### Added
* replication-status follows replication: every DR and performance peer a reachable cluster reports is checked too (health, replication state, WAL lag and TLS certificate), round by round, using the TLS settings of the context it was found through, and shown as discovered via that context.
### Fixed
* replication-status no longer warns about DR secondary clusters: the 472 that the active node of a DR secondary returns from sys/health is healthy. Standby and performance standby nodes still warn.
